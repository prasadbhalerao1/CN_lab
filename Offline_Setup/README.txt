OFFLINE PYTHON INSTALLER (WINDOWS 64-BIT)
=========================================
Only use this if a Windows computer does not have Python. Check by running: python --version

1. Double-click python-3.12.10-amd64.exe
2. Tick "Add python.exe to PATH" at the bottom of the first screen.
3. Click Install Now. If you have no administrator rights, untick the "admin privileges" option.
4. Open a new terminal and run: python --version

This is the official python.org installer. Ubuntu normally has python3 already.
